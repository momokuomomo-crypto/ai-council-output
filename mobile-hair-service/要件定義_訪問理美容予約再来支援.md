# 要件定義（たたき台）: 訪問理美容の予約調整・再来促進・適格性確認ツール

本ファイルは三社会合（議事録 20260726_2051）の裁定に基づくたたき台。
**当初の「誰でも・時間問わず訪問」案は違法のため採用しない。** 合法に成立する
福祉理美容（来店困難者）向けに組み替えた要件を示す。**リリース前に、展開先
自治体の保健所確認と法務（行政書士/弁護士）レビューを必須とする。** 本書は
個別案件の適法性を保証する法律意見ではない。

## 0. 大前提（法規制・これが崩れると成立しない）

- 理美容の施術は原則、登録された理容所・美容所で行う（美容師法第7条／
  理容師法第6条の2）。出張は政令の「特別の事情」がある場合の例外のみ。
- 対象＝疾病・高齢・障害・寝たきり・認知症等で来店困難な在宅療養者・施設
  入所者、婚礼等の儀式直前、撮影・放送等の出演者 等（2026-03-26厚労省通知で
  対象例が整理・一部拡大。ただし個別判断が必要、自治体差あり）。**「忙しい／
  夜に切りたい」だけの一般客は対象外。**
- 施術者は有資格の理容師／美容師であること。フリーランスが単独で実施主体に
  なれるか・届出・店舗所属の要否は自治体差があり、**展開先の保健所へ事前
  文書照会して確定する**。
- 施行令の正確な号・文言、罰則の条番号・金額、衛生/記録要件は「要確認」。

## 1. 目的

適法な訪問理美容（福祉理美容中心）の事業者・施術者について、予約調整・
既存客の再来促進・法定適格性の確認と記録を効率化する軽量Webツール。
**新規集客（不特定の新規客獲得）は目的にしない。**

## 2. ターゲット

- 主: 1〜5名規模の訪問理美容事業者／フリーの有資格理美容師（B2Pro）
- 従: 介護施設・デイサービス・ケアマネ・利用者家族（B2B2C）
- 初期地域: 保健所確認を完了した1市区のみ
- 施術対象: 法的に出張が認められる者（来店困難者中心）に限定

## 3. スコープ外（初期に作らない）

- 法令・条例上の対象外となる一般客の自宅施術（＝当初コンセプト）
- 24時間の施術保証／深夜施術の訴求
- 不特定の施術者と客を突き合わせる自動マッチング（two-sided cold-start）
- オンライン決済・代金の預かり・立替
- 診断書・障害者手帳・介護記録・身分証画像の恒久保存
- 病名・詳細な健康/介護情報（要配慮個人情報）の保存
- 複数事業者テナント（まずは友人1人／1事業者）

## 4. 主な機能（優先順）

1. **既存客台帳 ＋ 再来リマインド・次回予約**（LINEまたはSMS/メール）
   —— 集客の"リピート"側に効く中核機能。
2. **法令ガード（適格性チェック）**: 予約依頼時に「来店困難／儀式直前／
   出演等」の対象事由の選択を必須化し、非該当は予約不可にする。最終適格性は
   施術者が確認し、判断を記録する。
3. **予約依頼フォーム**（利用者・家族・施設用）と手動承認式の日程調整。
   早朝・夕方枠は施術者が任意設定（"24h予約受付"は可、"24h施術"は不可）。
4. **施設ごとの複数人一括予約**（施設訪問の効率化）。
5. **施術記録・次回目安・衛生チェックの記録**（要配慮情報は持たず、区分と
   安全上必要な最小情報のみ）。
6. CSV出力、キャンセル・監査ログ。

## 5. MVP範囲

- **機能1（台帳＋再来リマインド）と機能2（法令ガード）のみ**。
- 1事業者（まず友人1人）・1自治体・30〜100利用者を想定。
- スマホ対応Webアプリ＋LINE連携。検索市場・口コミ・チャット・アプリ内決済は
  作らない。

## 6. データ・個人情報

- 取得: 氏名・連絡先・予約日時・メニュー・来店困難理由の区分・介助/安全上
  必要な最小情報のみ。
- **要配慮個人情報（病名・障害・介護の詳細）は保存しない**。自由記述メモを
  初期は持たない設計で回避。
- 利用目的・本人/代理人同意・閲覧権限・保存期間・削除手順を明示。通信暗号化、
  管理者の多要素認証、アクセスログ、バックアップ。

## 7. 法対応（プロダクト設計として）

- 予約時に対象事由の選択を必須化し、非該当を弾く（法令ガード）。
- 利用規約に「施術者が有資格であること」「出張は法定の対象事由に限ること」
  「施術者が適格性・衛生管理の最終責任を負うこと」を明記。
- 展開先自治体の保健所回答に基づく運用表を持つ。特定商取引法表記。
- 公開前に行政書士または弁護士のスポットレビュー。

## 8. テスト方針（たたき台）

1. 対象事由が非該当の予約依頼が、法令ガードで確実に弾かれること。
2. 台帳登録→再来リマインド→次回予約の一連フローが動作すること。
3. 施設一括予約で複数人の日程がまとまること。
4. 要配慮個人情報の入力欄が存在しないこと（設計で持たない）。
5. 個人情報の削除手順が機能すること。

## 9. 未決事項（要確認・リリース前に潰す）

- 友人が有効な理容師／美容師免許を保持しているか（無資格なら不成立）。
- 展開先1自治体で、フリーランスが実施主体になれるか・届出・対象範囲・
  衛生/記録要件（保健所へ文書照会）。
- 施行令「特別の事情」の正確な号・文言・最新改正、罰則の条番号・金額。
- 収益モデル（月額2,980〜4,980円/施術者 or 施設単位月額5,000〜10,000円は仮説）。
- 狙いを (A)福祉理美容B2Pro業務支援 と (B)友人1人の既存客リピート支援 の
  どちらから始めるか（本会合の推奨は、まず B を最小で作り実使用を見る）。

## 9-2. 施術者（美容師/理容師）側の金額試算（全て仮説・要確認）

ツールの価値は「施術者の商売が成立していること」が前提のため、施術者側の
単位経済を試算する。**市場相場からの仮説値であり、友人ヒアリングと保健所
確認で実数に置き換えること。**

### A. 在宅（個人宅）訪問 — 施術者1人フル稼働

| 項目 | 仮説値 |
|---|---|
| 施術単価（カット中心） | ¥4,000/回 |
| 出張費（顧客負担・別途） | ¥1,000/回 → 顧客支払 ¥5,000/回 |
| 変動費（交通¥500＋消耗品¥200） | ¥700/回 |
| 1回あたり粗利 | 約¥4,300 |
| 1件の所要（施術30分＋移動/準備30分） | 実質60分 |
| 1日の件数（実働6h） | 約5件 |
| 1日 | 売上¥25,000／粗利¥21,500 |
| 月20日 | 売上¥50万／粗利¥43万 |

### B. 施設（介護施設等）まとめ訪問 — 効率型

| 項目 | 仮説値 |
|---|---|
| 施設向け単価（一括でやや低め） | ¥2,500/人 |
| 1回の訪問人数 | 10人 |
| 1訪問の所要（10人×25分＋移動） | 約4〜5時間 |
| 変動費（交通¥1,000＋消耗品¥2,000） | ¥3,000/訪問 |
| 1訪問あたり | 売上¥25,000／粗利約¥22,000 |
| 月20回（週5） | 売上¥50万／粗利¥44万 |

→ どちらも月商約¥50万・粗利¥43〜44万に着地。フリー施術者のフルタイム相当の
収入だが、**時間が上限でスケールしない**。単価を上げる（技術指名・特別ケア）か
施設契約で回転を上げないと伸びない。

### C. ツール価格の妥当性（施術者から見て）

- ツール月額 ¥2,980〜4,980/施術者（本要件の仮説）
- 施術者側の1件の粗利は¥4,300〜5,000。**ツールが再来/取りこぼしを月1件でも
  増やせば、ツール代は一発でペイ**。価格根拠＝「月1〜2件の追加・再来で回収」。

### D. ツール事業（提供側）の売上 ＝ 別の（小さい）数字

施術者が儲かることと提供側が儲かることは別。
- ¥4,000/月 × 施術者100人 = 月商¥40万（MRR）
- ¥4,000/月 × 施術者500人 = 月商¥200万

訪問理美容師は母数が限られる（フリー＋福祉特化）ため「**何人集められるか**」が
天井。前回会合の「薄利セグメント＋TAM小」の懸念と直結。**施設単位（1施設で
複数施術者・複数利用者）に寄せると1契約の単価が上がる**ため、施術者ツールは
入り口にして施設・家族側の収益を乗せる形が現実的。

## 10. 最初の検証（開発を広げる前に）

「保健所確認 → ヒアリング → コンシェルジュ運用」の順で、広告の実CAC・
対象該当率・予約成立率・再来率を実測する（詳細と合格基準は稟議書 8〜9節・
議事録参照）。**保健所確認が不明確なら開発を止め、確認済み美容所との提携型に
切り替える。**
