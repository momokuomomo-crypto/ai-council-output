### 査読席（Claude サブエージェント）— 全文は `stage1_査読席_出力.md`

**要旨**: 「課題文そのものが予想者を体系的に誤った方向へ誘導する構造を持っている」として3点を指摘。

2. **40.2%は全級別・全番組を混ぜた平均**であり、レース単位の予測値として使ってはならない。
   一律に掛けると **7Rと12Rでは過小評価、10Rと11Rでは過大評価**という方向の異なる誤りを同時に犯す。
3. **買い目戦略が期待値の観点で破綻しやすい**。3連単の払戻率は約75%。
   「自信度に応じて傾斜配分」は、市場も自信を持っているレース（＝オッズが沈むレース）に厚く張る指示であり、
   控除率を突破する方向とは逆を向いている。

**定量的な指摘（当地成績の分母逆算）**: 当地2連率と3連率は同じ分母の分数なので走数を復元できる。
実際に計算すると 嶋田貴支の当地勝率7.00＝**8走**、小池修平の当地3連率80.0＝**5〜10走**、

**当地3年間なのに大半が20走未満**（戸田はSG・G1開催が少なく遠方選手の来場機会が乏しいため）。

**事実訂正**: 課題文の「2022年5月1日にフライングの即日帰郷は廃止された」は不正確。

通常のフライングはもともと即日帰郷ではない。結論（滝沢・麻生が8/9も出走する）は変わらない。
また同一節2回目の**事故**（出遅れ・不良航法・転覆を含む）でも即日帰郷が適用されうるため、
8Rの②谷口健一（不良航法-10）・④中岡健人（転覆-5）にも同種の圧力がかかる可能性がある。

**結論**: レースごとに番組構造で基準値を分けよ（7R=55〜65% / 8R=35〜42% / 9R=30〜38% /
10R=25〜32% / 11R=25〜32% / 12R=48〜58%）。資金の軸を「自信度」から「オッズ条件付き期待値」へ。
**8Rと9Rは見送り。** 11Rは大平が7Rに出走するため金額確定は7R終了後。
12Rは6レース中で最も1号艇を信頼してよい（優勝戦のイン1着率は全国平均で通常番組比+10pt以上）。

## Stage 3: 統合・裁定（議長）

### 3-1. 議長による独立検証

裁定にあたり、査読席がStage 2で導入した検算手法を**全36艇に機械適用して独自に再計算**した
（`extract_pdf.py` の抽出結果から、進入回数と3連対数を「出走回数と一致する分解」で自動復元）。

**結果: 自動で一意に分解できた18件すべてが、査読席の提示値と一致した。**
残りは分解が一意に定まらなかったもの（全国コース別進入回数は事故回数を含み、出走回数は選手責任外の事故を含まないため
両者の合計が一致しないケース）で、これらは抽出結果の桁区切りから手動で確認し、やはり全件一致した。
**査読席の中核的な主張は、議長側の独立計算で裏付けられた。**

### 3-2. 議長が両席の結論を覆した点 — 8R・9Rの見送り

検証の過程で、**査読席自身はこの指標を7R・10R・11R・12Rにしか適用していなかった**ことが判明した。
8R・9Rに適用すると次のようになる。

| | 1号艇の自コース3連対率 | 戸田基準との差 | 対戦相手 |
|---|---|---|---|
| **8R ①楠将太郎** | 92.3%（13走） | **+22.4pt** | 5艇すべて基準割れ（②-36.2 / ④-29.0 / ⑤-22.0 / ③-13.3 / ⑥-5.3） |
| **9R ①奥田誠** | 93.8%（16走） | **+23.8pt（カード最大）** | ④松村のみ+14.8、②-18.4 / ⑤-19.8 / ⑥-17.0 |

**8R・9Rはカード中で最も1号艇が構造的に支持されている2レースである。**
両席の「見送り」は、査読席がStage 1で当地成績と今節成績の混乱から
「全艇に本命にする理由も消す理由も揃わない」と判断し、提案席がStage 2でそれをそのまま受け入れた結果であって、
**この指標に基づく検討を経ていない。**

ただし反証がある。**両艇とも今節の1コース戦で敗れている**（楠は2日目にST.06で6着、奥田は初日に4着）。
これは節間気配としての実質的な減点であり、構造的優位と相殺すべきである。

**裁定**: 全面見送りは採らない。同時に査読席の「エッジがないなら正しい金額はゼロ」という原則も正しいため、
構造的優位と直近の反証を相殺し、**8R=8口・9R=10口という薄い配分**とする。
これは両席の中間を取ったのではなく、**両席が適用しなかった指標を適用した結果**である。
なお稟議書の条件5として「両席がともに見送りを推奨したレースであると認識したうえで買うこと。買わない選択も正当」を課した。

## 付録: 未解決のまま残した論点

会合内で決着させられなかったもの。いずれも最終成果物の §8 に明記してある。

1. **7Rの大平の1着率の真値**（提案席58〜64% / 査読席50〜60% / 議長55%）。
   企画レースの編成は裏付けたが「67.6%」の集計期間・分母は不明。当日の展示とオッズでしか判定できない。
2. **12Rの木下の1着率**（提案席50〜56% / 査読席48〜58% / 議長52%）。
   優勝戦のイン上振れを戸田に適用する際の減衰率が不明。**戸田の優勝戦だけを切り出したサンプルは年間十数レース程度**で、
   統計的に信頼できる分場データは存在しない可能性が高い。最大配分のレースであり誤差の影響が最も大きい。
3. **10Rの湯川の評価。** 2コース3連対率54.5%（11走）は基準割れ、今節3日目は2走とも4着。
   A1という格と当地勝率7.59（17走）がこれを上回るのか、両席とも定量的に決着させられなかった。
4. **同一節2回目の「事故」で即日帰郷になる範囲**（F・L以外の不良航法・転覆を通算するのか）。
   8Rの②谷口健一・④中岡健人に慎重化圧力がかかるかはこの解釈に依存する。予想根拠には使わず、配分を薄くする理由に留めた。
5. **滝沢崚・麻生慎介の出走表「F1」表記が8/8のFを反映済みか。** 判別できず。
   ただし両席とも「F持ちによるST遅延の効果量は着順を反転させる大きさではない」で一致しており、買い目に影響しない。
6. **中核指標（コース別3連対率）が「全国」の値であり、戸田の水面特性を反映していないこと。**
   本予想の最大の弱点であり、会合内では解消できなかった。
