## 1. テーマ

AI開発用のデスクトップPCを購入予定。予算35万円前後（上限50万円）で、AI開発・学習、ローカルLLMの学習・検証、Python/Docker/FastAPI/Ollama/RAG/MCP/AIエージェント開発、Chrome拡張開発、普段使いを3年以上快適にこなせるWindowsデスクトップPCの構成（CPU・GPU・メモリ・SSD）を検討する。

## 3. 論点整理（Stage 0）

- 目的: 予算内で、AI開発（特にローカルLLM実行）と普段使いを3年以上快適にこなせる構成を決定する
- 制約: デスクトップ・Windows、3年以上使用、後からの大幅増設は避けたい、AI開発主目的だが普段使いも快適に、予算35万希望/50万上限
- 判定基準: (1)AI開発ワークロードへの適合性（特にVRAM/メモリ帯域）、(2)予算内でのコストパフォーマンス、(3)3年間・増設なしで通用する将来性、(4)普段使いの快適さ

## 4. 合意点

- **GPUはNVIDIA一択**。CUDA前提のエコシステム（PyTorch/bitsandbytes/vLLM等）が厚く、ROCmのWindows対応は2026年7月時点でも未成熟。開発時間を節約できる
- **CPUはRyzen 7で十分**。Ryzen 9・9800X3Dへの追加投資は本用途では非合理（X3Dはゲーム特化技術で「ゲームをほとんどしない」という条件と矛盾）
- **SSDは2TB必須**。Windows・開発環境・WSL2仮想ディスク・Dockerイメージ・モデル・データセットで1TBは早期に枯渇する
- **VRAM 16GBが実質的な上限**。RTX5060Ti／RTX5070Ti／RTX5080はいずれもVRAM16GBで同じ。予算を上げても「扱えるモデルの大きさ」はほとんど変わらず、変わるのは速度のみ。40万円から50万円への増額（RTX5080）は費用対効果が低く、**上限50万円を使い切る必要はない**
- **メモリは64GB（32GB×2）を推奨**。査読席は当初32GBを提案したが、AM5環境はDIMM4枚差し時にメモリクロックが大きく低下し「先に16GB×2、後から追加」という増設パスが事実上機能しない（丸ごと買い直しになる）ことが判明し、GPTの64GB案に収束した
- **RTX50 SUPER（24GB版）待ちは計画に組み込まない**。投入時期がCES2026説/2027説で併存し不確定
- **中古RTX3090（24GB）は却下**。保証なし・酷使個体リスク・価格急騰中で「3年以上安定利用」と相性が悪い
- **電源・ケース・マザーボードは将来のGPU換装を見越して余裕を持たせる**べき（850W以上・ATX3.1/12V-2x6、M.2スロット複数）。「増設したくない」という要望は、後付けが容易なメモリ・SSDではなく、こちらに適用すべき

## 5. 相違点

| 論点 | GPT（提案席） | Claude（査読席） |
|---|---|---|
| 価格提示の前提 | 40〜45万円を「本命」として一本化 | 自作/BTOで価格が10〜15%変わる点を明示。自作36〜44万円・BTO42〜50万円の幅で提示 |
| RTX5090の実勢価格 | 「基準価格約39万円から」（MSRP=定価） | 「実勢約69〜80万円」（査読が誤認と指摘、訂正） |
| クラウドGPU併用の位置づけ | 「不確実な点」として補足扱い | 「学習」定義次第では構成選定と同等以上の第一級の戦略 |
| OS エディション | Home可 | Pro推奨（Hyper-V直接利用・リモートデスクトップホスト・BitLockerがHomeでは不可） |
| SSD初期投資 | 2TB必須で一致 | （GPTの追加提案「今は最小限」への反論として）2TB必須を維持、両者一致 |

いずれも対立というより、査読席がGPT案の精度を補強・訂正した形で、最終的な収束度は高い。

## 6. リスク

- 「ローカルLLMの学習」の定義（推論中心／LoRA・QLoRA検証／それ以上）が未確定なまま構成を決めると、VRAM要件やクラウド併用の要否の判断を誤る
- 自作かBTOかを決めないまま「40万円台で収まる」と判断すると、BTO購入時に想定より4〜7万円程度の予算超過が起こり得る
- 2026年7月現在、DDR5・NAND・GPUが歴史的高値圏（DDR5は2025年7月比平均4.4倍等）にあり、本稿の価格情報は日次で変動する。購入直前の再確認が必須
- Windows 11 Homeで購入すると、後からHyper-V/リモートデスクトップホスト/BitLockerが必要になった際にProへの再セットアップコストが生じる
- AM5プラットフォームでメモリを32GBスタートにすると、64GBへの増設時にDIMMを丸ごと買い直すことになり、経済的でない

## 7. 論点ごとの評価

| 論点 | 採用した主張 | 根拠 |
|---|---|---|
| NVIDIA vs Radeon | 両席一致でNVIDIA | CUDAエコシステムの厚み、ROCmのWindows対応未成熟（査読席の追加調査で補強） |
| メモリ32GB vs 64GB | GPT案（64GB、32GB×2）を採用 | 査読席がAM5のDIMM特性を理由に自説を撤回し収束したため |
| CPU Ryzen7 vs Ryzen9 | 両席一致でRyzen7 | GPU/メモリへの予算配分の方が体感に効く。X3Dはゲーム特化で条件と矛盾 |
| SSD 1TB vs 2TB | 両席一致で2TB | モデル・Dockerイメージ・データセットの容量を踏まえ両席一致 |
| GPUグレード | RTX5070Tiを本命、RTX5060Tiを予算重視の代替、RTX5080は除外 | 両席とも「5080はVRAM同じで費用対効果が低い」で一致 |
| RTX5090の実勢価格 | 査読席の指摘（約69〜80万円）を採用 | GPTの「39万円から」はMSRP（定価）であり実勢と乖離、価格.com等の追跡データに基づく査読の訂正を採用 |
| 自作かBTOか | 未決着（次のアクションでユーザー確認） | 査読席のみが論点化。GPTの価格試算が自作前提と判明したため、ここは議長として保留し条件に格上げ |
| クラウドGPU併用 | 両席の温度差を両論併記 | 「学習」の定義（論点未決着）に評価が依存するため、議長裁定では確定させず次のアクションに残す |
| OS Home vs Pro | Pro推奨を採用 | 開発機としての将来の用途拡張（リモートアクセス等）を考慮 |

## 8. 裁定

**条件付き承認**

理由（目的適合性・制約充足・根拠の強さ・リスクの観点で）:

両席の意見は「NVIDIA・Ryzen7・SSD2TB・VRAM16GBで打ち止め・上限50万円は使い切らない」という骨格で高い収束を見せており、根拠も実勢価格データおよび技術的制約（メモリ帯域、AM5のDIMM特性、ROCmの対応状況）に基づいて具体的である。目的適合性（AI開発ワークロードへの適合）・制約充足（3年利用・増設回避・普段使い）は満たされていると判断する。査読席が自らの一次意見（メモリ32GB）を、技術的根拠（AM5の4枚差しクロック低下）に基づき自発的に撤回・訂正した点、およびGPTの数値誤り（RTX5090価格）を訂正した点は、本稿の結論の信頼性を高めている。

ただし、以下3点はユーザー本人でなければ確定できない未決着論点であり、これらの回答によって最終構成・最終価格が変わり得るため、**購入前に確定させることを条件**とする。

条件:
1. **「ローカルLLMの学習」の定義を明確にする**（推論中心か、LoRA/QLoRA検証か、それ以上か）。理由: これによりVRAM要件の妥当性評価とクラウドGPU併用の要否が変わるため
2. **自作かBTOかを決める**。理由: 同一構成で10〜15%（概ね4〜7万円）の価格差があり、「35万円/40万円台に収まるか」の判定自体が変わるため
3. **モニター等の周辺機器・OSエディション（Home/Pro）を予算内に含めるか確認する**。理由: 含める場合、本体予算をさらに5〜10万円圧縮する必要があり、GPUグレードの選択に直結するため

  - 上限50万円は使い切らない方針とする（RTX5080への増額、Ryzen9/X3Dへの変更は非推奨）
- 購入直前に価格.com等でGPU・メモリ・SSDの実勢価格を再確認する（2026年7月時点でも急変動中のため）
- 「学習」の定義次第で、クラウドGPU（RunPod等）併用を構成の一部として検討する
