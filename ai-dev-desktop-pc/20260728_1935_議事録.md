# 議事録: AI開発用デスクトップPC構成の選定

実施日時: 2026-07-28
検討体制: 議長（Claude Fable）、提案席（GPT / Codex CLI）、査読席（Claude サブエージェント）
ラウンド数: 1（既定）

---

## Stage 0: 論点整理（議長）

### テーマ

AI開発用のデスクトップPCを購入予定。おすすめの構成（CPU・GPU・メモリ・SSD）を検討する。

### 用途

- AI開発・学習、ローカルLLMの学習・検証
- Python / Docker / FastAPI / Ollama / RAG / MCP / AIエージェント開発
- Chrome拡張開発
- 普段使い（ブラウザ、Office、動画視聴など）

※ゲームはほとんどしない

### 条件

- デスクトップPC、Windows
- 3年以上使いたい
- 後から大きな増設はできるだけしたくない
- AI開発が主目的、普段使いも快適にしたい

### 予算

- 希望: 35万円前後、上限: 50万円、コストパフォーマンス重視

### 検討の目的・判定基準

- 目的: 上記予算内で、AI開発（特にローカルLLM実行）と普段使いを3年以上快適にこなせる構成を決定する
- 判定基準: (1)AI開発ワークロードへの適合性（特にVRAM/メモリ帯域）、(2)予算内でのコストパフォーマンス、(3)3年間・増設なしで通用する将来性、(4)普段使いの快適さ

### 実行計画

提案席（Codex CLI）・査読席（Claude subagent）を1ラウンド並列実行。Codex CLI呼び出しはStage1・Stage2で計2回。

## Stage 1: 独立意見

### 提案席（GPT）の一次意見

**要約**: AI開発用なら、最優先すべきはCPU性能ではなく、GPUのVRAM容量と開発環境への対応力。本命構成はRyzen 7 9700X + RTX 5070 Ti 16GB + 64GB DDR5 + 2TB NVMe Gen4、想定40〜45万円。

**立場**: 「Ryzen 7 9700X＋RTX 5070 Ti 16GB＋64GBメモリ＋2TB SSD」を選ぶ。優先順位：①GPUはNVIDIA・VRAM16GB以上 ②メモリ64GB ③SSD2TB ④CPUは現行Ryzen7 ⑤電源・冷却・保証 ⑥余裕があればGPU高速化。

**根拠**: NVIDIAはCUDAエコシステムの厚みで優位。RTX5070Tiは帯域896GB/秒でRTX5060Tiの448GB/秒の約2倍。RTX5070TiもRTX5080もVRAMは16GBで同じ。RTX5090（32GB）なら世界が変わるが基準価格約39万円からで予算大幅超過。

**主要な論点**:
1. 推奨構成: Ryzen7 9700X／RTX5070Ti16GB／DDR5 64GB(32GB×2)／NVMe Gen4 2TB／B650-B850／850W Gold／Win11 Home可
2. GeForce対Radeon: GeForce推奨。CUDA前提ライブラリ・トラブル情報の多さで開発時間を節約
3. メモリ32GB対64GB: 64GB推奨。WSL2+Docker+ブラウザ+IDE+ベクトルDB+複数コンテナ+ローカルLLM同時使用で32GBは余裕がなくなる
4. Ryzen7対Ryzen9: 基本的にRyzen7で十分。ゲームをほとんどしないためX3Dモデルも優先度低い
5. SSD1TB対2TB: 2TB推奨。Windows+開発環境+WSL2+Dockerイメージ+モデル+データセットで1TBは早期に不足
6. 価格帯別体感差: 35万円(5060Ti)→モデル適合範囲は確保も速度は遅い。40万円前後(5070Ti)→最もバランスよく本命。50万円(5080)→処理は速いが扱えるLLM規模はほぼ同じ
7. 最終選択: Ryzen7 9700X+RTX5070Ti16GB+DDR5 64GB+NVMe2TB、予算目標40万〜45万円

**不確実な点・前提**: 「学習」は7B〜14B級のLoRA/QLoRAを想定。30B〜70B級モデル常用ならクラウドGPU併用が合理的。価格は2026年7月時点でも変動する。

---

### 査読席（Claude）の一次意見

**要約**: 2026年7月現在のDRAM/NAND/GPU相場は歴史的高値圏（DDR5は2025年7月比平均4.4倍、NVMe SSDは底値比2〜2.7倍、RTX5090実勢約69〜80万円）。35万円構成と50万円構成でVRAM容量（16GB）は変わらず、体感差は限定的。

**立場**: 予算50万円をPC単体に投じる案には反対。二段構えを提案。
- 第一推奨（約33〜37万円）: Ryzen7 9700X / DDR5 32GB(16GB×2) / RTX5060Ti16GB / 2TB / 850W
- 第二推奨（約42〜46万円）: GPUをRTX5070Ti16GB、メモリを64GBに強化

**根拠**:
1. 実勢価格: DDR5 32GBキット約5.6〜6.2万円、64GBキット約9.5万円、NVMe2TB約4万円、RTX5060Ti約9.2万円、RTX5070Ti約15〜16万円、RTX5080約19.5〜23万円（VRAM16GBは同じ）、RTX5090約69〜80万円（定価39.38万円）
2. VRAMの壁: 9.2万円のGPUでも22万円のGPUでもVRAMは16GBのまま。「動かせるモデルの大きさ」はほぼ同じ
3. 「学習」の定義が曖昧。事前学習・フルFTは不可能。LoRA/QLoRAなら16GBで7〜14B級が現実的
4. システムメモリ帯域はVRAMの約1/10。64GBは開発環境の重さへの対応
5. 「増設したくない」の適用先が逆。メモリ・SSDは後付けしやすく、電源・ケース・マザーボードこそ将来を見越すべき
6. Ryzen9/9800X3Dへの追加投資は非合理（X3Dはゲーム特化技術で「ゲームしない」と矛盾）
7. RTX50 SUPER待ちは投入時期不確定
8. 中古RTX3090は保証なし・酷使個体リスクで却下

**未解決の論点**: 「学習」の定義、RTX50 SUPERの投入時期、モニター等が予算内/外か、週あたり実開発時間、メモリ・NAND高止まりの前提。

## Stage 2: 相互レビュー ラウンド1

### 提案席（GPT）のレビュー

**賛成**: VRAM16GBで規模は変わらない点、学習の定義を先に確定すべき点、Ryzen9/X3D非推奨、RTX50 SUPER待ち・中古RTX3090を基本案に含めない判断、電源/ケース/マザーボードを将来のGPU交換まで見越すべき点。

**反対**: 「上限50万円を使い切る合理的理由は薄い」への一律の結論は留保（長時間稼働なら速度差の価値は相応にある）。第一推奨のメモリ32GBは余裕が小さい。「速度1.5〜1.7倍」という数値は精度不足。クラウド併用が常に安いとは限らない。SSD「今は最小限」に反対、2TB必須を維持。

**追加提案**: 利用頻度別の3案（低〜中頻度＝5060Ti・32/48GB、高頻度＝5070Ti・64GB、大規模/フルFT＝クラウド分離）。購入前にVRAM所要量を試算すべき。マザーボードは4スロット確保しつつ、確実性重視なら最初から64GB(32GB×2)が安全。

**未解決の論点**: 学習の種別、週の使用時間、クラウド可否とデータ機密性、周辺機器の予算内外、騒音・筐体・消費電力の許容範囲、価格の購入時点再検証。

### 査読席（Claude）のレビュー

**賛成**: GPTの「40万→50万の増額は費用対効果低め」に全面同意（両席が独立に同結論へ収束）。Ryzen9/X3D非推奨、GeForce推奨（ROCmのWindows対応未成熟を根拠に補強）、SSD2TB推奨、GPTの帯域数値（896対448GB/s≒2倍）は自分の見積もり（1.5〜1.7倍）より正確と認め採用。

**反対（重要な訂正を含む）**:
- GPTの「RTX5090は基準価格約39万円から」は事実誤認。39.38万円はMSRPであり実勢は約69〜80万円。この誤認はユーザーに誤った希望を持たせるため訂正が必要
- GPTの価格見積もり（40〜45万円）は自作前提。BTOでは47〜52万円になり得る。「35万円に厳密に収める」構成も自作で36〜38万円、BTOで約42万円となり、実際には35万円に収まらない
- GPTは「今が部品の歴史的高値」という時間軸の文脈を扱っていない
- GPTはクラウドGPU併用を「不確実な点」に格下げしているが、査読席はこれを構成選定と同等以上の重要度を持つ論点と位置づける
- GPTの「Win11 Home可」は開発機として不適切（Hyper-V直接利用・リモートデスクトップホスト・BitLockerがHomeでは不可）。Pro推奨

**重要な自説の撤回**: 第一推奨のメモリ32GBを撤回し、GPTの64GB案を採用。理由：AM5環境はDIMM4枚差し時にメモリクロックが大きく低下するため、「16GB×2を先に買い、後から16GB×2を追加」という増設パスは事実上機能しない（丸ごと買い直しになる）。32GBキットと64GBキットの差額（約3.5〜3.9万円）を踏まえても、最初から32GB×2(64GB)にする方が合理的。**メモリ論点はGPTに軍配。**

**追加提案**: A案（5060Ti・自作36〜38万円/BTO約42万円）／B案（5070Ti・自作42〜44万円/BTO約47〜50万円、本命）／C案（5080・却下）の二層＋却下案の提示。AMD Ryzen AI Max+ 395（Strix Halo、128GBユニファイドメモリ、22〜30万円）を検討した上で却下（帯域256GB/sで実用速度不足、ROCm未成熟、拡張性なし）。ただし将来のサブ機候補としてメモ。RTX50 SUPER待ちは統一見解として「計画に組み込まない」。中古RTX3090は両席一致で却下として明記。

**未解決の論点**:
- A. 「今買うか、待つか」（未解決。ただし2025年以前の水準には戻らない可能性が高い）
- B. 自作かBTOか（未解決・かつ価格結論を左右する）
- C. 「学習」の定義（両席一致で最優先の確認事項）
- D. クラウドGPU併用の位置づけ（両席で温度差あり）
- E. 予算範囲の定義（周辺機器・OS含むか）
- F. 設置環境と静音要件
